# Point-in-time full reviews: 10 listings from the backtest

Each folder is a full DD-100 review **as of the token's first listing day on
Binance or Coinbase**, built only from information published before that
date. The reviewer (a research agent following `skills/crypto-dd`) was not
told how the token performed afterwards. Outcomes are compared in
`docs/BACKTEST.md` § Full reviews.
